# Ограничения

## Что сделано осознанно

- Matching с VERIFIED-корпусом без cross-building fallback
- Evidence только по сохранённым Frame.id; provenance неизменяем
- Impact preview только после вердикта; ScenarioRun не публикует график
- При неполной сети зависимостей — фрагментный прогноз без claim срока всего объекта
- Относительные пути кадров + единый резолв

## Частично / опционально

- Qwen / Ollama — не обязательны; прод-путь = шаблоны
- Resource leveling — упрощённый контур, не схема объекта
- Guided tour — ручная проверка сценария

## Не заявлять как готовую возможность

- Полный срок объекта при неполной сети КСГ
- «100 %» точности YOLO / AP50 с фикстур как прод-метрика
- ActivityNet в production path
- Авто-публикация КСГ и авто-оптимизация ресурсов
- Процент готовности работы из CV confidence
- Буровая / сваебойная как отдельный класс YOLO
