# Архитектура

PlanSight связывает календарно-сетевой график (КСГ) с наблюдениями с камер площадки и показывает эксперту проверяемые отклонения.

## Компоненты

| Слой | Технологии | Роль |
|------|------------|------|
| UI | Vite + React (`frontend/`) | Портфель, график, камеры, предупреждения, админка |
| API | FastAPI (`backend/app`) | Единый источник истины по данным и расчётам |
| БД | SQLite (`data/plansight.db`) | Проекты, КСГ, кадры, findings, вердикты |
| CV | YOLO (`app/services/cv_adapter`) | Детекция техники и людей на кадре |
| Знания | `knowledge/kb_v1.yaml` | Типы работ, техника, профили «что ожидаем на работе» |
| График | `app/services/schedule` | Импорт, сеть зависимостей, CPM, preview влияния |
| Пайплайн | `app/services/pipeline` | Кадр → зона → гипотеза → match → отклонение |

## Поток данных

```
КСГ + камеры
  → кадр → YOLO → зона (VERIFIED)
  → гипотеза работы → сопоставление со строкой КСГ
  → finding → вердикт эксперта → preview влияния на срок
```

## Режимы

- **HTTP (по умолчанию):** UI ходит в API; пустая БД → пустой интерфейс.
- **Локальное демо UI:** только при явном `VITE_DEMO_MODE=true` (localStorage), не смешивать с серверными данными.
- **AI:** по умолчанию `PLANSIGHT_AI_MODE=template` (шаблоны объяснений). Ollama/Qwen опциональны и не обязательны для работы продукта.
